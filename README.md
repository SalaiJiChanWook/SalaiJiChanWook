## 🌟 Featured Engineering Projects
*(Showcase Projects)*

### 1. 🛡️ [RPi Exam Forensic & Integrity Analyzer](https://github.com/SalaiJiChanWook/rpi_exam_forensic)
- **Tech Stack:** `Python 3 (Zero-Dependency)`, `Bash`, `Linux Kernel Auditing (journalctl)`, `SHA-256 Cryptography`, `HTML5/JS Dashboard`
- **Description:** An automated host-based forensic artifact collector and security integrity auditor built for air-gapped Raspberry Pi examination servers (MoodleBox / LAMP stack) operating in offline communities. Detects physical data exfiltration via USB drives, unauthorized database dumps, privilege escalation (`UID 0`/`sudo`), and anti-forensic history wiping.
- **Key Achievements:** 
  - Engineered a zero-dependency collection engine capable of running in strictly air-gapped environments without external package dependencies.
  - Built an All-in-One Interactive Forensic Workbench that embeds raw system logs, threat matrices, and cryptographic SHA-256 chain-of-custody verification into a single-file web console.

### 2. 📚 [Offline Edge Digital Library & LMS](https://github.com/SalaiJiChanWook/offline-edge-library-rpi5)
- **Tech Stack:** `Raspberry Pi 5`, `LAMP Stack (Apache, MariaDB, PHP 8.2)`, `Bash`, `Docker`, `Hostapd / DNSMasq`
- **Description:** A resilient, low-power edge-computing infrastructure built on a Raspberry Pi 5 to deliver offline digital library archives and LMS capabilities to remote, off-grid communities lacking internet connectivity. Features an automated provisioning stack, custom captive network resolution (`library.local`), and throughput-tuned storage permissions.
- **Key Achievements:** 
  - Engineered zero-bandwidth educational accessibility by transforming single-board hardware into a standalone Wi-Fi Access Point and local application server.
  - Optimized PHP memory and upload constraints (`1024M` post/upload buffers) to support concurrent offline multimedia distribution and large bundle course restorations.

- **Key Achievements:** Built a complete headless edge inferencing pipeline (~115ms/frame) with automatic duplicate prevention, offline Excel backups, background Google Sheets cloud sync, and a responsive web monitoring dashboard.
